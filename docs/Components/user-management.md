## [LMC Authentication](https://lm-commons.github.io/lmc-authentication)

Lmc Authentication offers middleware to implement authentication in your
application.

Lmc Authentication works in the same way as Mezzio Authentication except that
it does not perform any action when authentication does result into a user.

## [LmcUser](https://lm-commons.github.io/LmcUser)

LmcUser is a user registration and authentication module for Laminas MVC.
LmcUser provides the foundations for adding user authentication and registration
to your Laminas MVC application. It is designed to be very simple and easy to
extend.

:::warning
LmcUser is now in Maintenance-only.
See this [blog post](/blog/2025-07-01-mvc-maintanance-only.md)
:::
