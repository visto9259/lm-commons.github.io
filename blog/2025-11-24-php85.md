PHP 8.5 support has been added to the following packages.

PHP 8.1 support has been dropped for same packages.


- LmcUser V3
- LmcRbac V2
- LmcRbacMvc V4
- LmcCors V1
- LmcAdmin V2

Future LMC packages will support PHP 8.2 and up.
